# llmWikiRPG

llmWikiRPG is now RPG-only.

Legacy `llm_wiki` / `default` projects are not supported or migrated. The app only opens projects marked as `llmwikirpg`.

## Runtime Wiki Layout

- `wiki/sources/`
- `wiki/world/`
- `wiki/characters/`
- `wiki/player/`
- `wiki/locations/`
- `wiki/factions/`
- `wiki/items/`
- `wiki/plot-arcs/`
- `wiki/events/`
- `wiki/current-scene/`
- `wiki/relationships/`
- `wiki/style/`
- `wiki/rules/`
- `wiki/quests/`
- `wiki/memory/`

Legacy directories such as `wiki/entities/`, `wiki/concepts/`, and `wiki/queries/` are no longer product capabilities.
